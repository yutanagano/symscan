## 0.1.0

- First release
- Features:
  - Supports reading AIRR-compliant TSV files
  - Automatically generates a repertoire overlap matrix
  - Supports a within-cohort mode (when supplied only one input file) and a
    cross-cohort mode (when supplied with both query and reference input files)
  - Supports custom column names in input files
  - Supports using both Levenshtein and Hamming distances
  - Supports filtering by locus
